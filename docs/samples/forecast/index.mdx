# User guide sample: train your first forecast model

<span className="vp-label">Original sample, re-created for a fictional product.</span>

## Process note

These pages are for a demand planner training a first model: someone who has prepared data but has never chosen a selection metric or deployed a model, so the quick start explains the two concepts that block that reader (accuracy metrics and backtesting) at the step where they are needed, not on a separate concepts page.
I fixed one vocabulary for all five pages before drafting (setting names, input and output table names, button labels) and put the complete settings list in a single reference page, so the quick start and the retrain how-to each explain only the settings that matter at that moment and link out for the rest.
Next, I would add a troubleshooting page keyed to validation messages, and run the quick start with two planners to find the step where they stop.
