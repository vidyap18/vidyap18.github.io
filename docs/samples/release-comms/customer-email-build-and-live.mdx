# Pre-release email, Build and Live workspaces

<span className="vp-label">Original sample, re-created for a fictional product.</span>

**Subject:** Build and Live workspaces are coming to your Meridian Studio models: what to do before 17 March

On 17 March, Meridian Studio planning models will begin supporting separate Build and Live workspaces. This gives planners a dedicated place to build and test changes before they reach a stable Live version.

### Action required before 17 March

If anyone on your team has unsaved changes in the Quick edit bar, please save them before 17 March. Unsaved changes may not carry over when the new experience becomes available.

### What happens on 17 March

Each existing model automatically becomes its Build workspace. Its link, scenarios, data and user access stay unchanged, so no other immediate action is needed.

Your team keeps working in Build as it does today. When a model is ready, a planner can promote it to a separate Live workspace for business users. In Live, only settings the planner has approved stay editable, so the version your business users rely on changes only when you decide it should.

You choose which models to promote and when. There is no need to move everything at once. We do recommend moving stable models to Live over time, so building stays in Build and day-to-day planning happens in Live.

Planners will also see:

* **Edit mode and Preview mode:** build in Edit mode, see the business-user experience in Preview mode.
* **An updated Models page:** Build workspaces show by default, with a filter for models promoted to Live.
* **A new Promotion panel:** promote a model to Live and publish later changes from one place.

Release notes and step-by-step documentation will be available on 17 March.

Questions? Contact your Meridian customer success manager. We are happy to walk you through it.

Best,
The Meridian Studio team
