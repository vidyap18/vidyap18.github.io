# Help inside the product

<span className="vp-eyebrow">In-product guidance · since June 2025</span>

**What.** Guided tours, beacons, tooltips and pop-ups inside the product. Tours and beacons are published from the in-app help tool's editor with no engineering time; since 2026, tips and pop-ups also go straight into the product's code through pull requests.

![In-product pop-up for a pre-built analytics note](/img/work/note-popup.png)

*The pop-up for pre-built analytics notes, which replaces the in-app help tool's tips with native help. [Try the prototype](pathname:///prototypes/note-popup/). The product version is in review.*

## My part

- **Kicked off the rollout** with the vendor in June 2025: guided tours first, then in-app help, then banners.
- **Set limits on release beacons** in December 2025. A beacon now shows two or three times per user instead of five, offers "don't show again", and retires automatically after two weeks.
- **Tracked every tour and beacon** with an owner, a trigger and an end date.
- **Moved help into the product's own code** in 2026: info tips with "Learn more" links into the docs, tooltips and doc links in the transform tool, removal of outdated coach marks and beacons, and a native pop-up for every pre-built analytics note, with each step linking to the matching docs page.
- **Proposed a short release video inside the product**, November 2026, placed in the documentation tile so it does not interrupt work. Status: prototype, awaiting approval.

## What this shows

Treating in-product help as part of the documentation, and removing help that gets in the way.
