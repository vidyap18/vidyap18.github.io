# Help inside the product

<span className="vp-eyebrow">In-product guidance · since June 2025</span>

**What.** Guided tours, beacons and tooltips inside the product. The docs team publishes them in the in-app help tool's editor, so they need no product code change or engineering time.

## My part

- **Kicked off the rollout** with the vendor in June 2025: guided tours first, then in-app help, then banners.
- **Set limits on release beacons** in December 2025. A beacon now shows two or three times per user instead of five, offers "don't show again", and retires automatically after two weeks.
- **Tracked every tour and beacon** with an owner, a trigger and an end date.
- **Proposed a short release video inside the product**, November 2026, placed in the documentation tile so it does not interrupt work. Status: prototype, awaiting approval.

## What this shows

Treating in-product help as part of the documentation, and removing help that gets in the way.
