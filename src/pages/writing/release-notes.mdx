<h3>Sequence freshness</h3>

<p className="pg-note">For solution builders running long chains of notes. Shows which steps are working from stale data.</p>

<blockquote className="pg-quote">

An upstream Note reruns with new data. Somewhere downstream, a few Notes are still working from the old run, and nothing on the canvas tells you which ones. Until now, the only way to find out was to open Notes one at a time.

- **Four statuses**: **Current** means the Note reflects the latest upstream data. **Behind** means an upstream Note has newer data than this Note last ran with.

</blockquote>

<h3>Data type changes</h3>

<p className="pg-note">For everyone with data in the platform. A breaking-looking change that needs no action, explained so nobody panics.</p>

<blockquote className="pg-quote">

We have cleaned up the data types available in Meridian to make sure the data you put in comes back exactly the way you expect. No surprises, no silent errors. Your existing data is perfectly safe.

`Byte`, `Short`, and `Long` are consolidated into the `Integer` data type, while `Binary` is consolidated into `String`. The good news? You don't need to do a thing.

</blockquote>
</div>

<div className="pg-card">
<span className="pg-tag">Plain</span>

<h3>Rolling filters</h3>

<p className="pg-note">For data engineers loading from a warehouse. A small feature in a few lines.</p>

<blockquote className="pg-quote">

You can now pick a rolling window as the filter value in the Snowflake source Bridge, and it updates itself each time the Bridge runs.

- *Preset windows:* Pick Last Day, Last 7 Days, or Last 30 Days. No math required.
- *Smart anchoring:* `date` columns anchor to the sync's current date; `datetime` columns anchor to the current timestamp. You don't have to think about it.

</blockquote>
